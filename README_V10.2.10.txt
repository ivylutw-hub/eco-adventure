環保冒險王 V10.2.10｜講義延伸100題

本版修正：
1. Firebase 若重複匯入同一份 100 題 CSV，系統會自動依「題目文字」去重。
2. 講義延伸專區嚴格只顯示這 100 題，不會因重複資料出現 250／100。
3. 不會影響四大 Stage 的單元進度與原本 2,844 題。

部署：
1. 解壓縮本 ZIP。
2. 用本包的 index.html 覆蓋 GitHub Pages 根目錄的 index.html。
3. 將 lecture-focus-addon-v10.2.10.js 上傳到同一個根目錄。
4. 後台匯入「環保冒險王_講義延伸特訓_100題.csv」。
5. 網站按 Ctrl+Shift+R 強制重新整理。

注意：
- CSV 本身是 100 題且題目文字唯一。
- 即使 Firebase 中之前已重複匯入，V10.2.10 也會自動去重，不需要刪除舊資料。
