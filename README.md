## 環境部 AQI 設定

請至環境部環境資料開放平臺申請 API Key，並在 `config.js` 的 `MOENV_API_KEY` 填入金鑰。未設定時，首頁會顯示「官方資料待設定」，不會使用第三方數值推估。
