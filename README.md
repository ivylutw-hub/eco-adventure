# 環保冒險王 V10.2.8

這是環保冒險王的更新版，保留原有四大冒險、Firebase、守護基地、簽到、排行榜與題庫管理功能。

## 本次更新

新增「🌟 講義重點特訓｜50 題」獨立題庫區。這 50 題就是本次新增的講義重點題目，集中在同一個區域練習，不會混入原本四大冒險的 Stage／單元進度。

### 使用方式

1. 登入環保冒險王。
2. 首頁可在「冒險地圖」下方看到「🌟 講義重點特訓｜50 題」。
3. 也可以從上方主選單點「🌟 講義重點 50 題」。
4. 點「開始 50 題特訓」即可依序完成 50 題。

## 部署

將本次更新資料夾中的 `index.html` 與 `lecture-focus-addon.js` 上傳至 GitHub Repository 根目錄，覆蓋相同檔案；原本的 `questions.js`、`game.js`、`firebase.js` 等檔案維持不變。

本次功能採獨立 addon 方式加入，不修改原有題庫匯入架構。
